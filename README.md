# ค้นหาข้อมูลโภชนาการจากบาร์โค้ด

หน้าเว็บสำหรับสแกนหรือพิมพ์เลขบาร์โค้ดสินค้า แล้วดูข้อมูลโภชนาการต่อ 100 กรัม จาก [Open Food Facts](https://world.openfoodfacts.org)
เขียนด้วย HTML + CSS + JavaScript ล้วน ไม่ใช้ framework

## ความสามารถ

- พิมพ์เลขบาร์โค้ด หรือสแกนด้วยกล้องหลังของมือถือ (EAN-13, EAN-8, UPC-A, UPC-E)
- แสดงชื่อสินค้า ยี่ห้อ รูป และค่าพลังงาน น้ำตาล ไขมัน ไขมันอิ่มตัว เกลือ
- ป้ายสีบอกระดับ เขียว = ต่ำ, เหลือง = ปานกลาง, แดง = สูง

## โครงสร้างไฟล์

```
index.html   โครงหน้าเว็บ
style.css    การตกแต่ง (สี ฟอนต์ ขนาด)
script.js    การทำงานทั้งหมด
README.md    ไฟล์นี้
```

## ปรับเกณฑ์ป้ายสี

แก้ตัวแปร `LIMITS` ด้านบนสุดของ `script.js`

```js
const LIMITS = {
  sugars:       { low: 5,   high: 22.5 },
  fat:          { low: 3,   high: 17.5 },
  saturatedFat: { low: 1.5, high: 5 },
  salt:         { low: 0.3, high: 1.5 }
};
```

ค่า ≤ `low` คือ ต่ำ, ค่า > `high` คือ สูง, ระหว่างนั้นคือ ปานกลาง
ถ้าสินค้าไม่มีค่าเกลือแต่มีโซเดียม จะคำนวณ เกลือ = โซเดียม × 2.5

## เปิดใช้งานผ่าน GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดขึ้น repository (ต้องเป็น Public หากใช้บัญชีฟรี)
2. ไปที่ **Settings → Pages**
3. ที่ **Source** เลือก `Deploy from a branch`
4. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`

## ข้อควรรู้เรื่องกล้อง

| สถานการณ์ | กล้องใช้ได้ไหม |
|---|---|
| เปิดผ่านลิงก์ GitHub Pages (https) | ได้ |
| เปิดบนคอมผ่าน Live Server (`localhost`) | ได้ |
| ดับเบิลคลิกเปิดไฟล์ `index.html` ตรง ๆ | ส่วนใหญ่ไม่ได้ |
| เปิดบนมือถือผ่าน `http://192.168.x.x` | ไม่ได้ (ต้องเป็น https) |
| เปิดลิงก์จากในแอป LINE / Facebook | มักไม่ได้ ให้กด "เปิดใน Safari/Chrome" |

- iPhone ไม่รองรับการสั่นเครื่อง หน้าเว็บจึงไม่สั่นแต่ยังทำงานปกติ
- สแกนให้ได้ผลดี: แสงพอ ถือห่างประมาณ 15–25 ซม. ให้บาร์โค้ดอยู่ในกรอบแนวนอน
